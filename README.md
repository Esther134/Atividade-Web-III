# Galeria de fotos — Fatec Franco da Rocha

Projeto acadêmico de Desenvolvimento Web III feito com HTML, CSS e JavaScript, sem banco de dados. A validação consulta a API JSONPlaceholder e usa o `email` retornado como senha apenas para fins didáticos; isso não é autenticação adequada para produção. Depois do login, a aplicação carrega até 100 fotos, com busca, paginação e visualização ampliada.

## Como executar

1. Abra `index.html` em um navegador com acesso à internet. Se preferir, use a extensão Live Server do VS Code.
2. Entre com os dados abaixo para abrir a galeria.
